# SkillBridge AI

## Overview

SkillBridge AI is a prototype designed to help South African graduates prepare for employment through skills-based job matching and CV analysis.

## Problem

Graduates may struggle to identify suitable career opportunities, recognise skills gaps, and tailor their CVs to job requirements.

## Features

* Graduate career profile.
* Skills-based job matching.
* Preliminary CV keyword analysis against job descriptions.
* Identification of matched and missing keywords.
* CV improvement suggestions.
* Personalised learning recommendations.

## Technology Stack

* Python
* Streamlit
* pandas
* PyMuPDF
* python-docx

## Run Locally

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```

## Limitations

The current job listings are illustrative examples, not verified live vacancies. The CV checker provides preliminary keyword analysis and does not guarantee that a CV will pass an employer's applicant tracking system.

## Intended Users

South African graduates, final-year students, and early-career job seekers.
